# requirements.md - 初回実装の要求内容

対象: `.steering/20260905-initial-implementation/`

## 変更・追加する機能の説明

`docs/product-requirements.md` および `docs/functional-design.md` で定義した機能のうち、初回実装では以下を実現する。

1. ウォッチリスト管理(銘柄の登録・一覧表示・削除)
2. 銘柄詳細画面(シグナル要約 + 株価・財務データの表示)
3. シグナル調査の実行(検索プロバイダはモック実装から開始し、実APIキー未設定でも動作する)
4. 調査履歴の蓄積・時系列一覧表示
5. レスポンシブ対応の基本レイアウト

証券会社APIとの実連携、実際のWeb/YouTube/SNS検索APIとの接続は初回実装のスコープ外とし、アダプタ(インターフェース)とモック実装のみを用意する。実データ連携は後続の作業単位で追加する。

## ユーザーストーリー

- 個人投資家として、監視したい銘柄を証券コードと銘柄名で登録し、一覧で確認したい。
- 個人投資家として、登録した銘柄の詳細画面で「調査を実行」し、数量・単価シグナルの判定結果と根拠を確認したい。
- 個人投資家として、株価・財務データ(初回実装ではサンプルデータの取り込みでよい)をシグナルと並べて確認したい。
- 個人投資家として、過去に実行した調査を時系列で一覧・詳細確認したい。
- 個人投資家として、スマートフォンの画面幅でも操作に支障がないようにしたい。

## 受け入れ条件

- 銘柄をコード・名称で登録・削除でき、一覧に反映される
- 銘柄詳細画面で「調査を実行」を押すと、モック検索プロバイダを用いた調査が実行され、シグナル(数量/単価、増/減/不明)と根拠情報(出典・リンク・抜粋)が表示される
- 銘柄詳細画面に株価・財務データ(サンプルデータ)が表示される
- 調査履歴一覧画面で、実行済みの調査が実行日時順に表示され、各調査の詳細(シグナル・根拠)を確認できる
- スマートフォン幅(375px程度)でも主要画面のレイアウトが崩れない
- `npm run lint` / `npm run typecheck` / `npm run test` / `npm run build` が成功する

## 制約事項

- `docs/architecture.md` の技術スタック(Next.js App Router + TypeScript + Prisma + SQLite(開発用))に従う
- 外部APIキーが無くても一連の機能がモックデータで動作すること
- 秘匿情報をリポジトリにコミットしない
- `docs/development-guidelines.md` の命名規則・ディレクトリ構成に従う
